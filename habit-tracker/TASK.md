# Задача: Habit Tracker Mini App

## Требования

- [x] React, TypeScript, Vite, CSS и `@twa-dev/sdk`.
- [x] Мобильный интерфейс и заголовок «Мои привычки».
- [x] Четыре стартовые привычки и отметка выполнения.
- [x] Дневной прогресс: выполненное количество и процент.
- [x] Создание привычек с проверкой пустого и повторяющегося названия.
- [x] Сохранение привычек и даты выполнения в `localStorage`.
- [x] Тема Telegram, расширение Mini App и закрытие внутри Telegram.
- [x] Пустое состояние и сообщения об ошибках хранения.
- [x] Нет bot token, платных API, базы данных или UI-библиотек.
- [x] Документация запуска в `README.md`.

## Проверка вручную

- [ ] Запустить `npm run dev` и открыть адрес Vite на телефоне или в браузере.
- [ ] Убедиться, что отображаются все четыре стартовые привычки.
- [ ] Отметить и снять отметку: количество и процент должны обновиться.
- [ ] Перезагрузить страницу: привычки и отметки должны сохраниться.
- [ ] Добавить новую привычку; проверить пустой ввод и повтор названия.
- [ ] Открыть приложение с пустым сохранённым списком: должны появиться пустое состояние и форма добавления.
- [ ] Открыть Mini App в Telegram и проверить тему и кнопку закрытия.
- [ ] Убедиться, что `npm run build` проходит без ошибок.
