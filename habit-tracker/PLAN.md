# План разработки

1. Сохранить существующий проект React + TypeScript + Vite и использовать
   установленный `@twa-dev/sdk`, без дополнительных UI-библиотек.
2. Проверить мобильную компоновку: заголовок, дневной прогресс, список
   привычек, отметки выполнения и создание новой привычки.
3. Хранить привычки и отметки выполнения на текущий день в `localStorage`;
   показывать понятные ошибки чтения и записи.
4. Подключить Telegram Web Apps SDK для темы, расширения Mini App и кнопки
   закрытия только внутри Telegram.
5. Уточнить стили для клавиатурного фокуса и пустого списка; не добавлять
   секреты во frontend.
6. Проверить TypeScript и production-сборку командой `npm run build`, затем
   пройти ручной чек-лист из `TASK.md`.
